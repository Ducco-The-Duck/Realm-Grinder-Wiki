Challenges

Challenges are trials that you must complete for each faction. A challenge entails one or two main tasks that you may have to actively build towards, along with a number of minor objectives to tick off. Completing a challenge grants various bonuses. A challenge completed for a faction does not necessarily help that faction.

The Veteran Figurine lore artifact allows Mercenaries to benefit from all challenges.

Known bug, Mystic Maze: The reward text says "the highest amount of buildings you had in this Reincarnation", but the game uses the highest number you currently own of any single building type (including bonuses that make buildings count as more), which starts over every Era.
