# Data glossary

> **Repository note:** only `trophies.json`, `artifacts.json`, `icons.json`, `enums.json` and the
> generated pages under `docs/` are committed. Everything else listed below (engine, strings, entity
> files, formula values, sprite index) is derived from the game's code and text, is git-ignored,
> and is rebuilt locally from your own installation with the commands below.

Generated by `tools/build_data.py` from the decompiled game scripts. Rebuild with:

```
sh tools/extract.sh                # SWF -> out/   (needs raw/RealmGrinderDesktop.swf)
python -I tools/parse_mo.py        # out/binaryData -> data/strings.json
python -I tools/build_data.py      # out/script -> data/*.json
python -I tools/as3js.py           # out/script -> data/engine.js (+ engine_names.json, engine_report.json)
python -I tools/eval_formulas.py   # engine.js  -> data/formula_values.json
```

`tools/pylib/` (git-ignored) holds `quickjs` + `esprima`, installed with
`pip install --target tools/pylib quickjs esprima`. They are only needed for `as3js.py`/`eval_formulas.py`.

## Files

| File | Contents |
|---|---|
| `strings.json` | Every translatable string: `{english_msgid: {de_DE, es_ES, fr_FR, it_IT, pt_BR, ru_RU}}`. Plurals are `singular\0plural`. Names/descriptions in the other files are English msgids, so look them up here for translations. |
| `upgrades.json` | Upgrades, trophies, faction/elite upgrades, tech etc. (class family `§`6§`). |
| `achievements.json` | Achievements ("t:" ids). |
| `spells.json` | Spells. |
| `buildings.json` | Standard + alignment buildings and their unique-building names. |
| `researchs.json` | Research tree entries ("urs:" ids). |
| `enums.json` | Faction and alignment tables. |
| `engine.js` | The game's formulas and helper code transpiled to JavaScript (~1,870 classes). Call `__boot()` once, then use `__byQ[class]`, `__byId["u:FastForward"]`. Game state lives in the `K8G` static fields. |
| `engine_names.json` | Obfuscated token -> JavaScript identifier used in `engine.js` (and `formulas` keys, via the `_` prefix). |
| `engine_report.json` | Members that could not be transpiled (6) and why. |
| `sprites.json` | Sprite index `{name: [{atlas, file, width, height}]}` for the sliced atlases. Entity `icon` values are sprite names. The full set lives in `assets/sprites/` (git-ignored; regenerate with `tools/slice_atlases.py`). `docs/assets/icons/` + `icons.json` (sprite name -> file) hold the committed subset used by entity and trophy `icon` fields (`tools/export_icons.py`). |
| `runtime_icons.json` | `{class: sprite name}` for icons the game assigns at runtime (read off registered instances by `tools/runtime_icons.py`); `build_data.py` merges them into `icon` with `icon_runtime: true`. |
| `trophies.json` | Every entry in the game's trophy registry (1,220): `name`, `requirement` (rendered game text), `icon`, `type`, `alignment`, `group`, `listed`. `listed: true` are the 903 regular trophies; the rest are grouped `special` (56), `seasonal` (102), `excavation` (106), `event-quest` (53) by the game's own flags. Group names are inferred from their contents. `category` is the game's trophy tab (0 Allegiances, 1 Misc, 2 Magic, 3 Buildings, 4 Secret) and trophies sharing a `type` are tiers of one trophy. The 56 `special` entries are internal (53 have no icon) and are not shown on the page. Written by `tools/export_trophies.py`; page built by `tools/build_trophies_page.py`. |
| `artifacts.json` | The 106 archaeology artifacts (25 quest, 81 lore): `name`, `flavor` (shown after finding), `hint` (shown before), `requirements` (unlock condition decoded from the game code), `undecoded_conditions` (count of clauses not yet translated). Written by `tools/export_artifacts.py`; page by `tools/build_archaeology_page.py`. |
| `formula_values.json` | Results of every zero-argument static formula and every rendered description, at fresh-game state. Keys are `class` values from the entity files. |

## Record fields

Every record has `class` (obfuscated class name; stable across rebuilds of the same game version),
`kind`, optional `ids` (internal string ids such as `u:FastForward`), `num_id`, `name`.

| Field | Meaning | Confidence |
|---|---|---|
| `faction` / `faction_name` | 0 Fairy … 10 Drow, 11 Mercenary (see enums.json) | high – matches `XFaction` tags and names |
| `alignment` / `alignment_name` | 1 Good, 2 Evil, 3 Neutral, 0 none | high |
| `cost` | base cost (units depend on `category`/kind) | medium |
| `category` | small int (0–4) on upgrades/achievements; 4 = trophy-style upgrades | low – raw code, meaning not confirmed |
| `cost_growth` | per-purchase cost multiplier (buildings, default 1.15) | medium |
| `base_production` | building base output | medium |
| `building_index` | tier within an alignment's building line (1–11; Hall of Legends is 11, alignment 0 buildings are shared) | high – confirmed by registry |
| `unique_names_list` | unique-building variants by index | high |
| `duration` | spell value (`+` field); may be duration or cooldown | low |
| `spell_tier` | spell tier field | low |
| `formulas` | static helper functions from the class, expression text (names of game-state helpers stay mangled) | – |
| `texts` | every `_("…")` description with its argument expressions; `values` holds args that were constant | – |
| `refs` | other entities referenced by the class (prerequisites, related upgrades) | medium |
| `raw` | fields not yet labelled, keyed by mangled name | – |

## Known gaps

- `formula_values.json` is a fresh-game snapshot (nothing owned, no spells cast). Many values are
  state-dependent (e.g. Corrosion depends on time spent in the Era and shows NaN at t=0); drive them
  by setting `K8G` statics / instances before calling, which is what the wiki will need to expose.
- 6 formulas and ~31 descriptions throw in the engine (mostly reads of runtime-only UI/state
  objects, e.g. `toString` of an unset value); they are omitted from `formula_values.json`.
- 6 members could not be transpiled (stack-machine leftovers or unusual syntax); see
  `engine_report.json`. Library classes (Starling, Feathers, PlayFab, Kongregate) are stubbed.
- `templated: true` records (names like `param1`) are generated by a shared class, e.g. per-faction
  "Archeology X Trophy"; the final name is built at runtime.
- Sprites: 4,135 sliced; 1,081 distinct icons are used. ~300 entities legitimately have no icon; 17 name sprites that exist in no atlas (Exchange/Union/Anniversary/Valentine upgrades; Union icons only exist as `...Balance/Chaos/Order` variants).
